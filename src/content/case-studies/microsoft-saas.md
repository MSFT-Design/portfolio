## Context

Led the design of configurable systems used across enterprise, consumer, and education products within Microsoft.

The work required balancing scale with flexibility across multiple SKUs.

## Problem

Different products required variation while maintaining consistency in interaction and implementation.

## Approach

Focused on configuration rather than duplication.

Ensured all variations were supported within a single system.

## System Design

**Slot-Based Components**  
Flexible structures that scale across use cases

**Configuration Layer**  
Enabled features based on backend capability

**Telemetry-Driven Decisions**  
Used data to prioritize high-frequency interactions

Accessibility was defined at the system level to ensure consistency across platforms.

## Outcome

- Enabled scalable rollout across products
- Reduced duplication and maintenance cost
- Maintained consistent user experience

## Reflection

Configuration is more scalable than duplication.

Data should guide interaction prioritization.

Accessibility must be embedded early to avoid rework.
